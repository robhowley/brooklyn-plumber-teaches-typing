## Next-phase data API

Use **`assets/render/manifest.json` directly**, generated by `tools/render/decode.py`; do not read an invented `app/data.json.worlds` field.

- `worlds.water` / `worlds.castle`: background, per-character palettes, frame indices, BAN/ANI member bindings and callback metadata.
- `worlds.castle.scenes`: four scene records with dimensions, origins, inclusive bounds, source offsets and pixel hashes; clip changes and temporary save/set/restore sites are also exposed.
- `sprites`: resolve by **family plus index**, never global array position. There are289 records (145 IDLE plus144 world/inline sprites).
- Resolve every `indicesPath` relative to `assets/render/`, including raster paths in the separate `ani-tables.json`; BAN metadata remains in `ban-packets.json`.
